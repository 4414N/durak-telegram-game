# 🃏 Дурак — Telegram Mini App

Полноэкранная мультиплеерная версия для игры в группе Telegram, максимум 3 человека.

## Что внутри

- настоящий Web UI, а не набор bot-кнопок;
- закрытые руки: каждый игрок видит только свои карты;
- стол, козырь, колода, атака, защита, «забрать», отбой;
- WebSocket для мгновенной синхронизации;
- Telegram `initData` проверяется на сервере;
- общий room key берётся из `chat_instance` при запуске Mini App из контекста чата;
- адаптация под тему Telegram + fullscreen;
- пасхалки и игровые реплики;
- Docker-образ для деплоя.

## Важно про Telegram

Mini App должен быть доступен по HTTPS (для продакшена). Создайте приложение бота через @BotFather и назначьте short name `durak` (или укажите другой в `APP_SHORT_NAME`). У Mini App должен быть URL вида:

`https://t.me/<BOT_USERNAME>/<APP_SHORT_NAME>`

Именно этот deep link бот отправляет пользователю по `/start` и `/durak`.

## Запуск

1. Скопируйте `.env.example` в `.env`.
2. Вставьте **новый** Bot Token в `BOT_TOKEN`.
3. Укажите публичный URL.
4. На сервере:

```bash
docker compose up -d --build
```

Для локальной проверки без Telegram WebView можно открыть `/`, но авторизация Telegram будет отсутствовать.

## Безопасность

Bot Token никогда не передаётся в браузер. Сервер валидирует `Telegram.WebApp.initData` по HMAC перед присоединением игрока к комнате.
